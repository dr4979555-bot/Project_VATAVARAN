## 📋 Overview

Project VATAWARAN connects directly to four key Indian Government meteorological and disaster management digital platforms across both upstream prediction inputs and downstream emergency alerting.

## 1. Upstream Numerical Weather Prediction (MoES / NCMRWF)

### 1.1 NCMRWF Global Ensemble Prediction System (NEPS-G)

- **Agency:** National Centre for Medium Range Weather Forecasting (NCMRWF)
- **Protocol:** OpenDAP / THREDDS Data Server (TDS) & FTP
- **Endpoint:** `https://opendap.ncmrwf.gov.in/thredds/dodsC/NEPSG`
- **Resolution:** 12 km horizontal grid, 70 vertical levels
- **Lookahead Horizon:** 3 to 10 days (24h to 240h lead times)
- **Input Variables Extracted:**
  - $U_{850}, V_{850}$ (Zonal & meridional winds at 850 hPa)
  - $U_{200}, V_{200}$ (Upper-tropospheric jet winds at 200 hPa)
  - $Z_{500}$ (Geopotential height at 500 hPa)
  - $T_{850}, T_{2m}$ (Atmospheric & surface temperatures)
  - $Q_{700}$ (Specific humidity at 700 hPa)
  - $TP$ (Total accumulated precipitation)

### 1.2 IMDAA 12 km Regional Reanalysis Baseline

- **Agency:** NCMRWF / IMD
- **Protocol:** OpenDAP / NetCDF Subset Service (NCSS)
- **Endpoint:** `https://rds.ncmrwf.gov.in/opendap/IMDAA`
- **Purpose:** 40-year climatological baseline (1979–2020) used to compute the **Extreme Forecast Index (EFI)**:
  $$\hat{X}_t = \frac{X_t - \mu_c(d)}{\sigma_c(d) + \epsilon}$$

## 2. Ground Observation & Radar Validation (IMD)

### 2.1 IMD Automated Weather Station (AWS) Network

- **Agency:** India Meteorological Department (IMD)
- **Protocol:** REST API (`mausam.imd.gov.in/api/aws/realtime`)
- **Telemetry Frequency:** 15-minute to hourly intervals
- **Purpose:** Ground-truthing and continuous calculation of forecast bias ($\Delta T$, $\Delta \text{Rain}$) against the 5 km downscaled tensor.

### 2.2 IMD Doppler Weather Radar (DWR) Composites

- **Frequency:** 10-minute updates
- **Products:** Max-Z reflectivity (dBZ) and Plan Position Indicator (PPI) for convective precipitation cell benchmarking.

---

## 3. Satellite Remote Sensing (ISRO / SAC / MOSDAC)

### 3.1 INSAT-3DR & INSAT-3DS Imager / Sounder Feeds

- **Agency:** Space Applications Centre (SAC), ISRO / MOSDAC
- **Protocol:** HTTPS / STAC API (`mosdac.gov.in/api/v1`)
- **Key Geophysical Products:**
  - **Hydro-Estimator (HE):** Half-hourly satellite rain rate ($mm/h$)
  - **Cloud Motion Vectors (CMV):** Atmospheric motion vectors across pressure levels
  - **Outgoing Longwave Radiation (OLR):** Deep convective cloud identification ($W/m^2$)

## 4. Downstream Disaster Alerting (NDMA Sachet CAP v1.2)

### 4.1 Standardized Alert Delivery

VATAWARAN generates official **ITU-T Recommendation X.1303 / OASIS CAP v1.2** XML and JSON payloads formatted for the **NDMA Sachet National Disaster Alerting Portal**.

### 4.2 Endpoint Specifications in VATAWARAN

| Method | Endpoint | Description | Format |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/v1/gov/sources` | Live health and latency for all government data providers | JSON |
| `GET` | `/api/v1/gov/ncmrwf/cycle` | Current NCMRWF NEPS-G / NCUM operational model cycle metadata | JSON |
| `GET` | `/api/v1/gov/imd/stations` | Real-time IMD AWS ground station readings and model bias stats | JSON |
| `GET` | `/api/v1/gov/mosdac/satellite` | Latest INSAT-3DR & 3DS satellite observation feed | JSON |
| `GET` | `/api/v1/gov/cap/alerts` | Active NDMA Sachet CAP v1.2 alerts for tracked anomalies | JSON |
| `GET` | `/api/v1/gov/cap/export/{anomaly_id}` | Download official ITU-T X.1303 CAP v1.2 XML Document | XML (`application/xml`) |

## 6. How to Configure & Test

1. Copy `.env.example` to `.env`:

   ```bash
   cp .env.example .env
   ```

2. Start the VATAWARAN backend server:

   ```bash
   python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
   ```

3. Test Government Endpoints:

   ```bash
   # Check government source statuses
   curl http://localhost:8000/api/v1/gov/sources

   # Check IMD Ground AWS observations
   curl http://localhost:8000/api/v1/gov/imd/stations

   # Download official NDMA Sachet CAP XML
   curl -O http://localhost:8000/api/v1/gov/cap/export/BOB-CYCLONE-2026-01
   ```

4. Open the interactive dashboard in your browser at `http://localhost:8000`. You can:

   - Inspect the **Gov Feeds** status ribbon at the top.
   - Click **IMD Ground AWS Telemetry** to toggle station pins and view live readings.
   - Click **ISRO MOSDAC** to inspect INSAT-3DR satellite verification data.
   - Select an anomaly and click **Export CAP XML** or **View Sachet JSON** for emergency alerting.
