2. DATA PIPELINE & PREPROCESSING SPECIFICATIONS
--------------------------------------------------------------------------------
2.1 Ingestion Sources
  - NCMRWF Global Ensemble (NEPS-G): 12 km grid spacing, 6-hour temporal 
    resolution, 3 to 10 day lead-time projections.
  - NCMRWF Unified Model (NCUM): 12 km deterministic run.
  - Baseline Climatology: ERA5 reanalysis (1991–2020) and IMDAA 12 km reanalysis.
  - Static Geospatial Fields: SRTM 30 m Digital Elevation Model downsampled to 
    5 km; ESA WorldCover land-use land-cover fractions at 5 km.

2.2 Atmospheric State Vector ($X_t$)
At every forecast time step $t$, the atmospheric vector $X_t$ is constructed as:
  $$X_t = \left[ U_{850}, V_{850}, U_{200}, V_{200}, Z_{500}, T_{850}, T_{2m}, Q_{700}, TP \right]$$
Where:
  - $U_p, V_p$: Zonal and meridional wind components at level $p\text{ hPa}$ ($\text{m}\cdot\text{s}^{-1}$)
  - $Z_{500}$: Geopotential height at $500\text{ hPa}$ ($\text{m}^2\cdot\text{s}^{-2}$)
  - $T_{850}, T_{2m}$: Temperature at $850\text{ hPa}$ and $2\text{ m}$ surface ($\text{K}$)
  - $Q_{700}$: Specific humidity at $700\text{ hPa}$ ($\text{kg}\cdot\text{kg}^{-1}$)
  - $TP$: Total accumulated precipitation ($\text{kg}\cdot\text{m}^{-2}$)

2.3 Anomaly Standardization
Anomalies are normalized against the 30-year climatological mean ($\mu_c$) and 
standard deviation ($\sigma_c$) for day-of-year $d$:
  $$\hat{X}_t = \frac{X_t - \mu_c(d)}{\sigma_c(d) + \epsilon}$$
where $\epsilon = 10^{-6}$ prevents division by zero.


3. STAGE 1: SPHERICAL GRAPH NEURAL NETWORK (GNN) SPECIFICATIONS
--------------------------------------------------------------------------------
3.1 Mesh Representation
To prevent polar coordinate distortion and non-uniform pixel areas inherent in 
equirectangular projections, the Earth's surface is discretized using an 
icosahedral geodesic mesh recursively subdivided to Level 6 ($L_6$):
  - Total Vertices ($\mathcal{V}$): 40,962 nodes.
  - Total Triangular Faces: 81,920 faces.
  - Mean Node-to-Node Spacing: ~105 km (optimal for macro synoptic tracking).
  - Graph Topology: Represented as $\mathcal{G} = (\mathcal{V}, \mathcal{E})$, 
    where each node $v_i \in \mathcal{V}$ maintains node features $h_i^{(t)} \in \mathbb{R}^{d_{in}}$, 
    and edges $e_{ij} \in \mathcal{E}$ represent 3D Cartesian Euclidean displacement 
    vectors and geodesic distances on the sphere.

3.2 Spatio-Temporal Message Passing Architecture
Message passing across spherical nodes is governed by:
  $$m_{ij}^{(t)} = \phi_e \left( h_i^{(t)}, h_j^{(t)}, e_{ij} \right)$$
  $$h_i^{(t+1)} = \text{GRU} \left( \sum_{j \in \mathcal{N}(i)} \alpha_{ij} m_{ij}^{(t)}, \, h_i^{(t)} \right)$$
Where:
  - $\phi_e$ is an Edge MLP with LayerNorm and GELU activations.
  - $\alpha_{ij}$ represents multi-head spatial self-attention weights.
  - $\text{GRU}$ is a Gated Recurrent Unit tracking temporal feature transitions.

3.3 Extreme Forecast Index (EFI) Formulation
The EFI quantifies the divergence between the $M$-member forecast cumulative 
distribution function $F_f(x)$ and the climatological baseline CDF $F_c(x)$:
  $$\text{EFI} = \frac{2}{\pi} \int_0^1 \frac{p - F_f(F_c^{-1}(p))}{\sqrt{p(1-p)}} \, dp$$
The model isolates active anomaly clusters where $\text{EFI} \ge 0.80$ using 
spherical DBSCAN. Trajectory paths are smoothed with a Kalman filter to output 
a dynamic bounding box tensor:
  $$\mathcal{B}_{\text{anom}} = [Lat_{\min}, Lat_{\max}, Lon_{\min}, Lon_{\max}, T_{start}, T_{end}]$$


4. STAGE 2: AMPLITUDE-PRESERVING DIFFUSION DOWNSCALING SPECIFICATIONS
--------------------------------------------------------------------------------
4.1 Formulation & Objective
Standard $L_2$ regression models predict the conditional expectation $\mathbb{E}[y|x]$, 
which mathematically flattens localized high-intensity extremes. VATAWARAN 
formulates downscaling as conditional generative modeling via a Denoising 
Diffusion Probabilistic Model (DDPM).

Target Output: High-resolution 5 km tensor $y_0 = [TP_{5km}, U_{10m}, V_{10m}, T_{2m}]$.
Conditioning Vector: $c = [\hat{X}_{\text{coarse}}, \text{DEM}_{5km}, \text{LSM}_{5km}]$.

Forward Diffusion Process:
  $$q(y_t \mid y_0) = \mathcal{N}\left( y_t; \, \sqrt{\bar{\alpha}_t} y_0, \, (1 - \bar{\alpha}_t) \mathbf{I} \right)$$

Reverse Denoising Step:
  $$p_\theta(y_{t-1} \mid y_t, c) = \mathcal{N}\left( y_{t-1}; \, \mu_\theta(y_t, t, c), \, \Sigma_\theta(y_t, t, c) \right)$$

4.2 Physics-Informed Multi-Objective Loss Function
The model parameter weights $\theta$ are trained using a combined objective:
  $$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{diff}} + \lambda_1 \mathcal{L}_{\text{mass}} + \lambda_2 \mathcal{L}_{\text{moist}} + \lambda_3 \mathcal{L}_{\text{grad}}$$

Where:
  1. Score-Matching Denoising Loss:
     $$\mathcal{L}_{\text{diff}} = \mathbb{E}_{t, y_0, \epsilon} \left[ \left\| \epsilon - \epsilon_\theta(y_t, t, c) \right\|^2 \right]$$

  2. Mass Conservation (Kinematic Incompressibility Kernel):
     Enforces horizontal divergence constraints on surface wind fields:
     $$\mathcal{L}_{\text{mass}} = \left\| \nabla_H \cdot \vec{V}_{10m} \right\|^2 = \left\| \frac{\partial U_{10m}}{\partial x} + \frac{\partial V_{10m}}{\partial y} \right\|^2$$
     Computed via 2D finite-difference Sobel convolution operators.

  3. Moisture Flux Convergence Constraint:
     Prevents the hallucination of extreme precipitation ($TP$) without 
     corresponding low-level moisture convergence:
     $$\mathcal{L}_{\text{moist}} = \left\| \operatorname{ReLU}\left( TP_{5km} - \left[ -\nabla \cdot (Q_{700} \vec{V}_{850}) + \Delta Q \right] \right) \right\|^2$$

  4. Gradient Amplitude Preservation:
     Forces retention of high-frequency spatial variation and steep peak values:
     $$\mathcal{L}_{\text{grad}} = \left\| |\nabla y_{\text{pred}}| - |\nabla y_{\text{true}}| \right\|_1$$

Hyperparameter Weights: $\lambda_1 = 0.05$, $\lambda_2 = 0.10$, $\lambda_3 = 0.02$.

4.3 Accelerated Inference Sampling
Sampling is executed via the Denoising Diffusion Implicit Models (DDIM) 
scheduler over $N = 50$ steps (reduced from 1000 steps), yielding a 20x 
inference speedup with negligible metric degradation.

7. VERIFICATION, QA TESTING & OPERATIONAL RUNBOOKS
--------------------------------------------------------------------------------
7.1 Benchmark Test Cases (Historical Retrospectives)
  - Case 1: Super Cyclone Amphan (May 2020)
    * Pass Criteria: Stage 1 tracks Bay of Bengal landfall trajectory with 
      <= 30 km centroid displacement at 72 hours. Stage 2 retains wind speed 
      extrema >= 150 km/h in coastal Sunderbans.
  - Case 2: 2022 North India Extreme Heatwave
    * Pass Criteria: Accurately identifies 850 hPa geopotential ridge. 5 km 
      downscaled surface temperatures retain the 99th percentile maximums 
      within 1.2 deg C of ground-based Automated Weather Station (AWS) records.
  - Case 3: 2023 Western Himalayan Torrential Rain / Flash Floods
    * Pass Criteria: Topographically conditioned diffusion prevents spatial 
      leakage of high-intensity rain bands over leeward rain-shadow zones.

7.2 Quality Assurance Gating Thresholds
  - Physical Conservation Audit: If $\mathcal{L}_{\text{mass}} > 0.05$ or 
    $\mathcal{L}_{\text{moist}} > 0.15$ on output tensors, the generation is 
    flagged as invalid.
  - Fail-Safe Fallback Procedure:
    1. Worker detects physics validation failure or GPU timeout (> 60 s).
    2. System triggers bicubic spline downscaling augmented with elevation 
       lapse-rate adjustments ($-6.5\text{ K}/\text{km}$).
    3. Output JSON flags `"degraded_mode": true` and issues broad-brush 
       meteorological warnings with explicit uncertainty caveats.
